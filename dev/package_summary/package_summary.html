R package · breeding-program simulation

tidybreed by the numbers

A database-first breeding-program simulator. Every genotype, haplotype and record lives in a file-based DuckDB database rather than in R memory, so simulations can exceed RAM, resume after a crash, and archive replicates. A small Rcpp kernel handles meiosis and recombination.

genome_effect_member_originsScope of a member, as a predicate over allele copies. No rows = the common scope, which matches every copy. An additive member takes at most one row; a genotype member takes an exact multiset whose copy counts sum to the realized copy count. genome_effect_lociView: one row per (term x locus), with locus_name joined from genome_meta. The place to answer which loci are causal for a trait; locus_name lives only here, so there is no id/name agreement invariant to keep in the base tables. view 8 — define_genome() kept
