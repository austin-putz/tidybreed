Swine

Swine programmes typically select on growth, feed efficiency, carcass, reproductive, and maternal traits simultaneously. Key modelling notes: litter size requires a repeatability model (PE per sow); piglet birth weight has a maternal component (dam uterine capacity / milk); pen growth and competition benefit from SGE models.

# Litter size — repeatability model
pop |>
  define_trait("NBA", target_add_var = 0.3) |>
  get_table("genome_meta") |> define_additive_effects("NBA") |>
  define_phenotype("NBA",
    trait_type   = "count",
    mean         = 12,
    min_value    = 0,
    max_value    = 22,
    residual_var = 0.6,
    repeatable   = TRUE) |>
  define_effect_random("NBA", "pe", source_column = "id_ind", variance = 0.25)

# Piglet birth weight — direct + maternal composite

  define_trait("BW_maternal", target_add_var = 0.04) |>
  define_phenotype("BW_piglet",
    trait_type   = "continuous",
    mean         = 1.4,
    residual_var = 0.05,
    components   = tibble::tribble(
      ~source_trait_name, ~contributor_type,
      "BW_direct",        "self",
      "BW_maternal",      "dam"
    )
  )

Layer Poultry (Egg Producers)

Layers are among the most complex species to simulate because (1) the laying curve is naturally modelled as a reaction norm over weeks of production, (2) many egg quality traits are correlated, (3) sex-limited production traits require careful handling, and (4) broodiness and persistency are key selection targets. This is one of the two most profitable Hendrix BUs — complete coverage is critical.

# Laying persistency — Legendre RR over 40 production weeks
pop |>
  define_trait("L0_eggs", target_add_var = 0.15) |>
  define_trait("L1_eggs", target_add_var = 0.05) |>
  define_trait("L2_eggs", target_add_var = 0.02) |>
  get_table("genome_meta") |>
  define_additive_effects(c("L0_eggs", "L1_eggs", "L2_eggs"), G = G_rr_eggs) |>
  define_phenotype("egg_production",
    trait_type    = "count",
    mean          = 0,
    residual_var  = 0.8,
    expressed_sex = "F",
    repeatable    = TRUE,
    components    = tibble::tribble(
      ~source_trait_name, ~contributor_type, ~weight_type, ~covariate_name, ~poly_order, ~poly_scale_min, ~poly_scale_max,
      "L0_eggs", "self", "legendre", "week", 0L, 1, 40,
      "L1_eggs", "self", "legendre", "week", 1L, 1, 40,
      "L2_eggs", "self", "legendre", "week", 2L, 1, 40
    )
  )

# Sample one record per hen per week
for (wk in 1:40) {
  pop <- pop |>
    get_table("ind_meta") |>
    filter(sex == "F") |>
    add_phenotype("egg_production", covariate_values = list(week = wk))
}

# Correlated egg quality traits (EW, HU, SS) — multi-trait joint model
R_quality <- matrix(c(4.0, 1.2, 0.8,
                      1.2, 2.5, 0.6,
                      0.8, 0.6, 1.0), 3, 3,
                    dimnames = list(c("EW","HU","SS"), c("EW","HU","SS")))
pop |> define_effect_cov_matrix("residual", R_quality)

# Turkey BW — very large sex effect + heterogeneous residual variance
pop |>
  define_trait("BW_turkey", target_add_var = 400) |>
  get_table("genome_meta") |> define_additive_effects("BW_turkey") |>
  define_phenotype("BW_turkey",
    trait_type   = "continuous",
    mean         = 8000,           # overall mean (g) — males ~12 kg, females ~7 kg
    residual_var = 600) |>         # unconditional default
  define_effect_fixed_class("BW_turkey", "sex",
    source_column = "sex",
    levels        = c(M = 2500, F = 0)) |>   # large sex shift
  add_residual_cov("BW_turkey",              # males have larger residual
    cov_matrix       = matrix(900, 1, 1, dimnames = list("BW_turkey","BW_turkey")),
    condition_column = "sex", condition_level = "M") |>
  add_residual_cov("BW_turkey",
    cov_matrix       = matrix(400, 1, 1, dimnames = list("BW_turkey","BW_turkey")),
    condition_column = "sex", condition_level = "F")

Salmon (Atlantic Salmon)

Salmon has some unique features: a known major QTL for IPN resistance (very large additive effect at the INHA locus), grilsing is a binary early-maturation trait under strong selection, and sea lice resistance is increasingly important. Multi-environment (freshwater vs. sea) reaction norms are used.

# IPN resistance — large single-locus QTL (INHA region)
# Assign near-Mendelian effect to one locus, polygenic background to rest
inha_locus <- "Locus_5423"   # the known QTL locus
pop |>
  get_table("genome_meta") |>
  filter(locus_name == inha_locus) |>
  define_additive_effects("IPN_resist",
    effects = 2.5) |>     # very large effect allele substitution
  get_table("genome_meta") |>
  filter(locus_name != inha_locus, chr %in% 1:29) |>
  define_additive_effects("IPN_resist",
    distribution = "normal") |>   # polygenic background
  define_phenotype("IPN_resist",
    trait_type   = "binary",
    prevalence   = 0.40)          # ~40% mortality in challenge test

Shrimp (Pacific White Shrimp / Black Tiger Shrimp)

Shrimp presents the most significant simulation challenge: individual tagging is difficult (PIT tags cause mortality, fin clips require killing), so most commercial programmes rely on family selection with tank-level phenotypes. The framework handles the genetics correctly; the phenotype side requires workarounds for truly anonymous individuals.

Black Soldier Fly (BSF — Hermetia illucens)

BSF is the most challenging species from a simulation standpoint. Larvae in a production batch cannot be individually identified, so nearly all economically important traits are batch-level measurements. The framework can simulate the genetics if individuals are tracked (e.g. in a nucleus with individual larval tracking), but true commercial batch phenotypes without individual IDs require additional design work.

Larval period length Add Y If tracked
Fat content of larvae (batch) Group M Batch measurement; group phenotype workaround
Protein content (batch) Group M
Dry matter content Group M
Female fecundity (egg clutch size) Cnt Y expressed_sex="F", trait_type="count"

      ~source_trait_name, ~contributor_type, ~group_column, ~aggregation,
      "larva_weight",     "group",           "bin_id",      "sum"
    )
  )

Summary of Known Limitations

Limitation Affects Planned Fix
Anonymous batch phenotypes (no individual ID) Shrimp (tank survival), BSF (batch yield) Not yet designed; needs family-phenotype model
Covariate-continuous heterogeneous residuals RR traits (Var(e) varying with DIM) Noted in Q5; requires extending phenotype_residual_cov with poly columns
Dominance effects All species with inbreeding or crossbreeding Planned; depends on genome_effects extension
Epistasis effects All Planned; further out
Higher-order polynomial fixed covariates Growth curves, dose-response Q10: add poly_order to trait_effects
Spline basis functions Complex reaction norms Not planned
Time-to-event / survival analysis Disease challenge survival time Not planned; binary threshold approximation available
Social dominance rank (competitive hierarchy) Poultry pen, fish rank Not planned; complex ordering phenotype
Multi-environment GxE (formal reaction norm index) Salmon sea vs. freshwater M: can use covariate-based RR as approximation
