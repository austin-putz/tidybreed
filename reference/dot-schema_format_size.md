# Format a byte count for the `schema()` Size column

Format a byte count for the
[`schema()`](https://austin-putz.github.io/tidybreed/reference/schema.md)
Size column

## Usage

``` r
.schema_format_size(b)
```

## Arguments

- b:

  Numeric vector of bytes.

## Value

Character vector; `"?"` for `NA`.
