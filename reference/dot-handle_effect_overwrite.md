# Handle duplicate effect_name: stop or delete existing row

Handle duplicate effect_name: stop or delete existing row

## Usage

``` r
.handle_effect_overwrite(pop, phenotype_name, effect_name, overwrite)
```

## Arguments

- pop:

  A `tidybreed_pop` object.

- phenotype_name:

  Character scalar.

- effect_name:

  Character scalar.

- overwrite:

  Logical.
