# tidybreed: Tidy Breeding Program Simulation

A next-generation R package for breeding program simulation that uses
tidyverse-style design and pipe operators. Provides flexible,
memory-efficient tools for simulating animal and plant breeding programs
with support for complex mating designs, trait architectures, and
selection strategies.
