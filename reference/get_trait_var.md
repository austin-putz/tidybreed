# Get the variance (diagonal) for one trait from trait_var_comp

Get the variance (diagonal) for one trait from trait_var_comp

## Usage

``` r
get_trait_var(pop, effect_name, trait_name)
```

## Arguments

- pop:

  A `tidybreed_pop` object.

- effect_name:

  Character.

- trait_name:

  Character.

## Value

Numeric scalar, or `NA_real_` if not found.
