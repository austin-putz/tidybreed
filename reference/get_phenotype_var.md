# Get the variance (diagonal) for one phenotype from phenotype_var_comp

Get the variance (diagonal) for one phenotype from phenotype_var_comp

## Usage

``` r
get_phenotype_var(pop, effect_name, phenotype_name)
```

## Arguments

- pop:

  A `tidybreed_pop` object.

- effect_name:

  Character.

- phenotype_name:

  Character.

## Value

Numeric scalar, or `NA_real_` if not found.
