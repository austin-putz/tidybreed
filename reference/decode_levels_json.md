# Decode a level-map JSON string produced by `encode_levels_json()`

Decode a level-map JSON string produced by
[`encode_levels_json()`](https://austin-putz.github.io/tidybreed/reference/encode_levels_json.md)

## Usage

``` r
decode_levels_json(s)
```

## Arguments

- s:

  Character scalar, or `NA`.

## Value

Named numeric vector (possibly length 0), or `NULL` if missing/empty.
