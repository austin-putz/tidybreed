# Genetic variance components a target can be stored for

Routed to `trait_var_comp` by
[`define_effect_cov_matrix()`](https://austin-putz.github.io/tidybreed/reference/define_effect_cov_matrix.md).
A finite list, not a pattern: a name moves here when a generator can
calibrate it.

## Usage

``` r
GENETIC_EFFECT_NAMES
```
