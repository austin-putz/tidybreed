# Pre-built `_schema_meta` descriptions — Genome group

Covers genome_meta, genome_map, genome_effects, and the two
per-chromosome rule tables. One function per display group in
[`schema()`](https://austin-putz.github.io/tidybreed/reference/schema.md);
the group vector in
[`.schema_table_order()`](https://austin-putz.github.io/tidybreed/reference/dot-schema_table_order.md)
and these functions must name the same tables.

## Usage

``` r
.genome_descriptions()
```
